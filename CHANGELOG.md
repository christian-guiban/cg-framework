# Changelog

## 1.0.0 - 2026-11-18
- Initial release of CG Framework.
- Added responsive theme templates and WordPress theme supports.
- Added WooCommerce hooks and gallery support without copied template overrides.
- Added Elementor compatibility and Theme Builder core locations.
- Added shortcode generator and two built-in shortcodes.
- Added dashboard CPT/taxonomy manager.
- Added theme guide, screenshot, documentation and asset structure.

## 1.1.0 - 2026-11-20
- Added Website Information Customizer controls for phone, email and physical address.
- Added `[gcf_option]` shortcode with text and semantic link output modes.
- Extended the shortcode generator with Website Information field and output selectors.
- Added opt-in Elementor v3 compatibility Customizer checkbox, conditional stylesheet and extension hooks.
